Your PMDB key is sent securely to this server to authorize the migration. It is kept encrypted in server memory and decrypted when needed to contact PMDB, not saved in cookies or files. Your session lasts one hour. When a migration ends, its key and the key held by sessions using it are released; the session can still read results until it expires. Reconnect to start another migration.

Disconnect PMDB ends your session, but does not stop a running migration or revoke your API key at PMDB.

Your data and privacy

        
Your imported export and migration logs are saved in this browser so you can return to them. Closing the tab does not delete them or stop a running migration.

        

            What is stored, for how long, and how to delete it
            
In your browser: the imported export expires 24 hours after import; logs expire separately, 24 hours after their first entry. This page checks for expired data when you open it and every minute while it stays open. If the browser is closed, expired data remains stored until you return to this site.

            
After migration: once this page receives a successful result, it removes the imported export from browser storage. If the migration fails or only partly succeeds, the export stays available for retry until its expiry. Logs remain until their own expiry.

            
On our server: the ZIP is opened in your browser. Only the fields needed for your selected migration steps are sent to the server and used to import data into PMDB. The export filename and Trakt profile stay in your browser. The app processes migration data in server memory and releases its references to job data when the job ends; this is not guaranteed secure erasure of every memory copy. A completion summary remains temporarily available for reconnecting, with a 10-minute expiry; expired summaries are removed by periodic cleanup, and may be removed sooner when capacity is reached.

            
Your PMDB key: it is kept encrypted in server memory, with temporary decryption when needed. Your browser receives a session cookie, not the key. Sessions expire after one hour. When a job ends, the app releases its key and removes the key from sessions using it. Results-only access remains until the original session expiry. A running job retains its key even if you disconnect. Encryption does not protect against a fully compromised server.

            
You are in control: use Delete local export and logs above to remove this site's stored export and logs from this browser. Use Disconnect PMDB to end your session. Neither action cancels a running migration or removes data already imported into PMDB. Use Stop migration and disconnect to remove the session key and request that the worker stops. Results-only access remains so you can see the outcome. Already-sent requests may still finish; completed imports are not undone. Jobs have a 6-hour limit, checked between requests and processing checkpoints; an in-flight request can extend this. To revoke the API key itself, do so in PMDB.

            
Files on your device: the original ZIP and any logs you download are not deleted by this site. Delete those files yourself when you no longer need them. Browser storage is separate for each browser and site address.
